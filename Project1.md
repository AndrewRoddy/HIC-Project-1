# **CS 32301 Human Interface Computing Fall 2026 Department of Computer Science Kent State University** 

**Project 1: Applying the 8 Golden Rules of Interface Design** 

## **Group size:** 4 students **Total marks:** 100 

Develop a **simple** website/software application/mobile app that demonstrates the 8 golden rules of interface design discussed in class (lecture 2). Your group may choose **any application** purpose and use **any programming language/framework** . 

## **Requirements** 

1. **Working implementation:** Develop a working application with functional navigation and interactions (static screenshots are not sufficient). 

2. **Distinct pages (screens):** Include **7–9 pages** , each serving a different purpose (function). Pages that differ only in text, images, or displayed records do not count as distinct pages. Shared elements, such as navigation menus and toolbars, should remain consistent. 

3. **Application of the golden rules:** Demonstrate all 8 golden rules across your application. Not every rule needs to apply to every page. 

4. **Documentation:** For each page or screen, provide a screenshot, describe its purpose and main interactions, and identify the golden rules it satisfies. Explain how specific interface features demonstrate each applicable rule (simply listing <u>the rules is not sufficient).</u> 

## **Submission Requirements** 

Submit one package per group containing: 

- **Source code** and **instructions** for running the application. 

- A **short report** listing the application purpose, the required descriptions, screenshots, and explanations for each page.
