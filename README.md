# HIC Project 1

Requirements

1. Working implementation
2. 7-9 distinct pages
3. Application of the golden rules
4. Documentation
5. And a short report, code and README file, how to run the code, explain what you have implemented

### Installation

To run the application first run

```
npm install
```

Then to run the application use

```
npm run dev
```

### Building the Report

The pdf report is commited in the `report/` directory.

If you would like to modify and rebuild the report, you can ue the following commands.

```
typst compile report/main.typ
```

If you would like to work on the report with live updating you can use

```
typst watch report/main.typ
```
